# System Monitor

A modern Linux System Monitor built using JavaFX.

It provides real-time monitoring of system resources including CPU, Memory, Disk, Network and running Processes through a clean desktop interface.

---

## Features

- Real-time CPU Monitoring
- Memory Usage Monitoring
- Disk Usage Monitoring
- Network Speed Monitoring
- Live Performance Graphs
- Running Process Viewer
- Process Search
- Terminate Processes
- Force Kill Processes
- Dark GitHub-inspired UI
- Expandable Performance Cards

---

## Technologies

- Java 17
- JavaFX
- Gradle
- MVC Architecture
- Linux /proc filesystem
